# 증거 기록 요약 (원문 비공개)

[`2026-08-23-third-party-validation.md`](../2026-08-23-third-party-validation.md) 가 인용한 증거 로그는 세 개였다. 원문에는 대상을 특정할 수 있는 정보(호스트 · 패키지 판 · 취약점 식별자)와 미해결 취약점 내용이 들어 있어서 공개본에서 뺐다. 아래는 각 로그가 무엇을 잰 기록이었는지만 적은 것이다.

| 원래 파일 | 무엇을 잰 기록인가 | 쓰인 곳 |
|---|---|---|
| `audit.log` | `npm audit` 출력. 프로덕션 의존성에 있는 high 취약점의 건수와, 고치려면 주 판(major)을 올려야 한다는 안내를 담았다 | G1 |
| `audit-detail.log` | 패키지별로 추린 감사 결과와 저장소 점검 결과. 패키지마다 심각도와 영향 범위를 적었고, 프레임워크 판 · `engines` 유무 · 추적되는 `.env` 수 · 스펙 파일 수와 소스 파일 수를 함께 담았다 | SUP-01 · OPS-02 · QA-03 · G3 |
| `secrets.log` | gitleaks 로 전 이력을 스캔한 출력. 스캔한 커밋 수 · 바이트 수와 「no leaks found」 결과를 담았다 | G2 · SEC-04 |

감사자가 세 로그 모두 명령을 직접 실행해서 얻었다. 대장의 근거등급 `measured` 는 이 출력에 근거한다.
