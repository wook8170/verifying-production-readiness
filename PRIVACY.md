# Privacy policy — verifying-production-readiness

Last updated: 2026-11-05

This plugin is one Claude Code skill with helper scripts that run on your own computer.

- **Data collected:** none. The plugin has no telemetry, no analytics, and no server of its own.
- **Data sent:** none. No script opens a network connection. Reports are written as local files in the project you audit, and they stay there until you delete them.
- **Downloads:** only when you run `ensure-tools.sh --install`, which installs `gitleaks` through Homebrew and missing delegate skills from Claude Code marketplaces you have already added. Those tools follow their own privacy terms.
- **Artifacts:** the skill may ask Claude to publish a rendered report as a claude.ai Artifact. That happens in your Claude session under Anthropic's terms, and you see the tool call.
- **Children:** the plugin is a developer tool and is not directed at people under 18.

Questions: open an issue at https://github.com/wook8170/verifying-production-readiness/issues.
