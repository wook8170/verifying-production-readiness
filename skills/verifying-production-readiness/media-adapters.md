# 매체 어댑터 — 웹이 아닌 대상에 축을 번역한다

`axes.md` 의 「어떻게」는 웹/SaaS 모양(라우트·CSP·헤드리스 브라우저)으로 적혀 있다.
대상이 웹이 아니면 **축을 빼지 말고 아래 표로 재해석**하라 — 축 번호는 그대로 유지한다
(번호가 흔들리면 다음 세션이 대장을 못 읽는다). 표에 없는 축(①⑤⑦⑧⑨)은 매체와 무관하게
원문 그대로 적용된다.

## 네이티브 데스크톱 앱 (macOS/Windows)

| 축 | 재해석 |
|---|---|
| ② 백엔드·API | 프로세스 간 계약: IPC·XPC·URL 스킴·서비스 핸들러 전수. 파일 포맷 하위호환. CLI 동봉 시 CLI 계약 |
| ③ UI·접근성 | OS HIG 준수 · VoiceOver/내레이터 완주 · 키보드 완주 · 다크/라이트 · 로케일(문자열 잘림) · **노치/멀티모니터** |
| ④ E2E | UI 자동화(XCUITest/AppleScript/접근성 API) 또는 사람 체크리스트. **실기기 스크린샷을 evidence 로** |
| ⑥ 보안 | 코드서명·공증·TCC/권한 프롬프트·자격증명 저장(Keychain/DPAPI)·자동 업데이트 채널 무결성 |
| ⑩ 배포·롤백 | 인스톨러/DMG/스토어 심사 · **이전 버전 데이터를 가진 채 업그레이드** · 다운그레이드 시 데이터 보존 · 언인스톨 잔여물 |
| ⑪ 관측성 | 크래시 리포터 연결 확인(실제로 한 번 죽여서 수집되는지) · 로그 회전 · **사용자가 로그를 보낼 수단** |

## 사용법

1. 착수 시 대상 매체를 정하고 `00-summary.md` 에 「매체: <X> — media-adapters.md 적용」을 적는다.
2. 해당 없음으로 뺀 축은 **뺐다고 적는다**(축 선택 규칙과 동일).
3. 판정선은 재해석된 「어떻게」에 맞춰 착수 전에 수치로 못 박는다(Iron Rule 1은 매체 불문).
